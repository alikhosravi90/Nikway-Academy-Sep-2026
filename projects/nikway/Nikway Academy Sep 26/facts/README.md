# NIKWAY Fact Registry

این پوشه محل تبدیل گزاره‌های مستند به Factهای قابل ارجاع است.

وضعیت‌ها:

- `confirmed`: گزاره در سند مرجع صریحاً ثبت شده است.
- `inferred`: گزاره از چند سند استنباط شده و نیازمند تأیید انسانی است.
- `proposed`: گزاره پیشنهادی است و هنوز Fact محسوب نمی‌شود.

قاعده: هیچ Fact بدون `source_refs` و `evidence` وارد Master نمی‌شود.
