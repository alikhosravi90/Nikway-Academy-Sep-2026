# NIKWAY Decision Registry

مرجع مرکزی تصمیم‌های معماری، محصول، دانش، AI و Runtime.

هر تصمیم باید:

- زمینه و مسئله مشخص داشته باشد؛
- گزینه‌های بررسی‌شده را ثبت کند؛
- تصمیم و پیامدها را توضیح دهد؛
- به Fact و Evidence متصل باشد؛
- وضعیت و trigger بازنگری داشته باشد.

تصمیم جدید نباید تصمیم قبلی را بی‌صدا حذف یا جایگزین کند.
