# Level 1 — Source of Truth

مرجع Git-based انسانی و version-controlled. فایل‌های این سطح باید از طریق Pull Request، review و ثبت تغییرات به‌روزرسانی شوند.

قالب‌ها:

- YAML برای manifest، ontology، registry و configuration
- Markdown برای توضیحات، ADR، SOP و گزارش انسانی
- JSON برای exchange و snapshot
- JSON Schema برای اعتبارسنجی ساختار
- OpenAPI برای قرارداد API
